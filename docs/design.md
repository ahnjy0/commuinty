## 1. 화면 구조

### 1.1 공통 레이아웃 골격

모든 화면은 최대 폭 **430px**(모바일 뷰포트)을 기준으로 하며 아래 3단 구조를 공유합니다.

```
┌───────────────────────────────┐
│ Header (fixed, h=56px)         │  ← 배경 blur(12px) + 반투명(80%) + 하단 shadow
├───────────────────────────────┤
│                                 │
│  Main Content (scroll)          │  ← 좌우 padding 16px, 상단 padding 56px(헤더 높이)
│                                 │     하단 padding 72~112px(하단 UI 높이만큼 확보)
├───────────────────────────────┤
│ Bottom Nav 또는 하단 고정 액션 │  ← 배경 blur(12px) + 반투명(90%) + 상단 shadow
└───────────────────────────────┘
```

- **Header**: 좌측 로고(`모디 MODI`) 또는 뒤로가기+화면명, 우측 알림 벨 아이콘 + 프로필 원형 아바타(32px)
- **Bottom Nav**: 홈 / 검색 / 내 정보 / 설정 4개 탭(h=64px), 활성 탭은 보라색 아이콘·텍스트 + 하단에 4px 원형 인디케이터 도트
- 로그인/회원가입/글작성/상세 등 "서브 화면"은 하단 탭 대신 **뒤로가기 헤더**(←, 로고, 화면 타이틀, 우측 프로필)를 사용

### 1.2 화면별 구조 요약

**홈 피드 (Feed)**
- 헤더 하단에 가로 스크롤 카테고리 필터 바(전체/일상/정보공유/질문답변/취미/리뷰, pill 버튼)
- 피드 카드 스트림(세로 16px 간격): 작성자 헤더(아바타+이름+뱃지+시간) → 제목/본문 2줄 요약 → 이미지(선택) → 메트릭 바(좋아요/댓글/북마크/공유)
- 우측 하단 플로팅 액션 버튼(FAB) "글쓰기"

**검색 및 탐색 (Search)**
- 상단 고정 영역: 검색 입력창(좌 아이콘, 우 지우기 버튼) + 검색 버튼, 그 아래 카테고리 탭(전체/게시글/사용자)
- 입력 전: 최근 검색어 chip 목록(삭제 가능) + 인기 검색어 랭킹 리스트
- 입력 후: 검색결과 섹션(사용자 매칭 카드 → 게시글 매칭 카드), 검색어는 하이라이트(`<mark>`) 처리

**설정 (Settings)**
- 섹션 카드 4개(둥근 모서리 16px, 흰 배경): ① 계정 및 개인화(미니 프로필 헤더+프로필수정+알림 토글+테마설정) ② 커뮤니티 및 콘텐츠 보호(차단 사용자/필터링) ③ 정보 및 고객지원(공지/약관/버전) ④ 계정관리(로그아웃 버튼 + 회원탈퇴 링크)
- 하단에 브랜드 감성 문구 + 저작권 footer

**내 정보 (My Profile)**
- 상단 유틸리티 바(타이틀+공유/QR 버튼) → 프로필 요약 카드(그라디언트 장식, 아바타+사진변경 버튼, 이름/아이디/뱃지, 자기소개, 3분할 통계(작성글/팔로워/받은좋아요), 프로필수정/QR 버튼)
- 세그먼트 탭(내가 쓴 글 / 좋아요한 글 / 작성한 댓글, 카운트 배지 포함)
- 게시글 리스트(썸네일 있는 카드/없는 카드 혼합), 리스트 끝에 "모든 게시글을 불러왔습니다" 안내

**로그인 (Login)**
- 브랜드 헤더(로고 배지+"모디 MODI"+서브카피) → 화이트 카드(이메일 입력, 비밀번호 입력+표시토글, 로그인상태유지 체크박스, Primary CTA 버튼)
- 소셜 로그인 구분선 + 카카오(#FEE500)/구글 버튼
- 하단 "회원가입" 유도 pill

**회원가입 (Sign Up)**
- 인트로(배지+타이틀+서브카피) → 프로필 이미지 업로드(96px 원형 + 카메라 버튼)
- 폼: 닉네임(+중복확인 버튼), 이메일(+인증번호 전송 버튼), 비밀번호, 비밀번호 확인 — 각 필드 실시간 검증 피드백(성공 시 초록 체크)
- 약관 동의 카드(전체동의 + 필수/선택 개별 항목)
- 큰 Primary CTA "회원가입 완료"(56px, radius 16px)

**게시글 상세 (Post Detail)**
- 작성자 정보 바(아바타44px+이름+인증뱃지+작성일시+조회수) + 팔로우 버튼
- 카테고리 배지 → 제목(h1) → 본문 → 메인 이미지(페이지네이션 "1/3") → 서브 이미지 2열 그리드 → 해시태그 chip 목록
- 좋아요/댓글/북마크/공유 액션 바(카드형, radius 16px)
- 구분용 회색 섹션 바(8px) → 댓글 영역(정렬 옵션, 댓글 카드 - 답글은 들여쓰기+연한 배경으로 스레드 표현, "작성자" 뱃지)
- 화면 하단 고정 댓글 입력창(아바타+pill input+전송 버튼)

**사용자 프로필 (User Profile, 타인 프로필)**
- 뒤로가기+이름/아이디 헤더 + 공유/더보기 버튼
- 프로필 카드(그라디언트 장식, 아바타80px+인증뱃지, 레벨 뱃지, 이름/아이디/소개, 3분할 통계, **팔로우**(primary) + **커피챗/메시지**(secondary) 버튼) — 내 프로필과 달리 수정 버튼 없음
- 세그먼트 탭(작성한 글/스크랩한 글) + 게시글 카드 리스트

## 5. 간격·모서리·그림자 톤

### 5.1 여백(Spacing)

- 화면 좌우 기본 여백: **16px**
- 컴포넌트 내부 padding: 4 / 8 / 12 / 16 / 20px 단위 사용 (4px 배수 스케일)
- 카드 사이 세로 간격: 8~16px
- 헤더 높이 56px, 바텀내비 높이 64px — 본문 콘텐츠는 이 높이만큼 상/하 padding 확보(`pt-56px`, `pb-72~112px`)

### 5.2 모서리 반경(Radius)

| 반경 | 사용처 |
|---|---|
| `9999px`(완전 원형) | 아바타, pill 버튼/뱃지, 토글, FAB |
| `16px` | 큰 섹션 카드(설정, 프로필 카드, 회원가입 CTA) |
| `12px` | 일반 카드, 입력창, 버튼, 썸네일 |
| `8px` | 작은 아이콘 배경, 태그 칩 |
| `6px` | 초소형 태그(해시태그 chip 등) |

### 5.3 그림자(Shadow)

- 카드 기본 그림자: `0px 1px 2px rgba(0,0,0,0.05)` (매우 은은한 elevation)
- drop-shadow 보조: `0px 1px 1px rgba(0,0,0,0.05)`
- Primary 버튼 컬러 그림자: `0px 4px 6px -1px rgba(65,65,203,0.2), 0px 2px 4px -2px rgba(65,65,203,0.2)` — 브랜드 컬러를 그림자에도 반영
- 상단 헤더/하단 고정 바: `backdrop-blur(12px)` + 반투명 배경(80~95%) + 방향성 있는 미세 그림자(헤더는 하단, 바텀바는 상단)로 플로팅 느낌 연출

### 5.4 전반적 톤

- 전체적으로 **"부드러운 라벤더/인디고" 톤 온 톤(tone-on-tone)** 배색: 배경(`#F8F9FF`)부터 표면(`#EFF4FF`~`#E5EEFF`)까지 같은 색상 계열의 명도 단계를 사용해 카드 구분은 미묘한 배경차 + 얕은 그림자로만 표현
- 강조가 필요한 곳(CTA, 활성 상태, 좋아요)에만 채도 높은 인디고(`#4141CB`/`#5B5CE5`) 또는 레드(`#B90538`)를 포인트로 사용
- 모서리는 전반적으로 크게(12~16px, 완전 원형 다용) 처리해 친근하고 부드러운 커뮤니티 앱 인상을 줌
